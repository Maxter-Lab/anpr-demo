# 🚘 ANPR Demo — распознавание автомобильных номеров

Демонстрационный проект для показа типового конвейера Automatic Number Plate Recognition (ANPR).

## Pipeline

1. Получение изображения или видеопотока.
2. Детекция автомобиля и/или области государственного регистрационного знака.
3. Распознавание символов (OCR).
4. Формирование структурированного результата.

## Технологии

- Python
- YOLO11n
- OpenCV
- PyTorch
- Edge AI / RDK X5 (целевое устройство для отдельного режима развёртывания)

## Результаты тестирования

| Показатель | Значение |
|---|---:|
| Edge-платформа | RDK X5 / BPU |
| Производительность | 11–15 FPS |
| Задержка обработки | около 480 мс |
| Точность на тестовом наборе | около 80% |

Значения относятся к конкретной тестовой конфигурации и не являются гарантией производительности на другом оборудовании или видеопотоке.

## Состояние репозитория

Это публичная витрина проекта. На текущем этапе опубликованы описание и начальный список зависимостей. Исполняемый `main.py`, веса моделей и демонстрационные данные ещё не включены, поэтому команды запуска появятся после подготовки переносимой версии приложения.

## Планируемая структура

```text
anpr-demo/
├── main.py
├── requirements.txt
├── README.md
├── models/       # локальные веса; не добавлять закрытые модели
├── assets/       # обезличенные демонстрационные материалы
└── samples/      # тестовые изображения/видео с разрешённым использованием
```

## Установка зависимостей

Текущий `requirements.txt` — стартовый список для Python-окружения с PyTorch и Ultralytics. Перед запуском на целевой платформе версии библиотек и способ установки PyTorch необходимо согласовать с ОС, архитектурой и доступным ускорителем.

```bash
python -m venv .venv
```

Активация окружения:

Windows:
```powershell
.venv\Scripts\Activate.ps1
```

Linux:
```bash
source .venv/bin/activate
```

Установка:
```bash
pip install -r requirements.txt
```
